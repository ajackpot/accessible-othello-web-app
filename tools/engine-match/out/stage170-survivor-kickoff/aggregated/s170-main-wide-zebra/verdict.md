# Verdict: `s170-main-wide-zebra`

## 결론
` s170-main-wide-zebra `는 **보류**로 두는 편이 맞습니다.

## 근거
패턴은 아래처럼 갈렸습니다.

- `s154-main`: **동률 -> 승리 -> 패배**
- `s154-both`: **승리 -> 패배 -> 동률**

전체 합산은 baseline `23.5/48`, candidate `24.5/48`로 candidate가 **아주 근소하게만** 앞섭니다.
하지만 이 `+1.0` 포인트는 시간축과 baseline축 어디에서도 clean하게 반복되지 않았습니다.

특히 이번 후보는
- `160ms`에서는 `s154-main`이 좋고 `s154-both`가 나쁘며,
- `240ms`에서는 `s154-main`이 나쁘고 `s154-both`가 동률로 수렴합니다.

즉 “시간이 늘수록 선형적으로 좋아진다”거나
“두 baseline 모두에서 같은 방향으로 반복된다”는 해석이 불가능합니다.

cost 쪽도 우호적이지 않습니다.
aggregated rows **6개 전부**에서 nodes/ms는 baseline이 더 높았습니다.

## 해석
그렇다고 바로 비채택으로 닫기도 이릅니다.

- 교차 결합 1순위 후보답게 `s154-both 80ms`는 꽤 좋았고,
- `s154-main 160ms`도 선명한 양수였습니다.
- overall도 완전 음수는 아닙니다.

따라서 이 후보는 **strength story가 완전히 사라진 후보**라기보다,
현재 표본에서는 sign flip이 너무 많아 결론을 고정하기 이른 **보류형 통합 후보**에 가깝습니다.
